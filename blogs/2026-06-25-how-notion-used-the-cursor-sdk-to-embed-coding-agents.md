Notion integrated Cursor's coding agents into their product using the Cursor SDK, completing the integration in weeks. The SDK's design aligned well with Notion's architecture, letting users delegate coding tasks directly from Notion while Cursor handles planning, building, testing, and PR creation with remote MCP support.
