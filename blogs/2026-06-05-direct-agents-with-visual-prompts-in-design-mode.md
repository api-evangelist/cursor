Cursor's updated Design Mode lets developers direct AI agents through visual prompts - clicking elements, drawing annotations, or using voice commands - to make UI changes more intuitively. Integrates with the Cursor browser to give agents both element identity and spatial context, enabling faster iteration alongside Composer 2.5.
